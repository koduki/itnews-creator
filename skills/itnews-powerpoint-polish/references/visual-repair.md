# ビジュアル修正の境界

既存PPTXのテンプレート書式を唯一の正本とし、色・座標・フォント・装飾値を別途指示しない。表紙の意図的な赤黒と、本文の青い見出しを含む各スライドの元デザインを保持する。

- 文字重なりやはみ出しは、元のテキスト枠内の最小限の調整で解消する。汎用カード・図形・テーマで描き直さない。
- NEWS_TITLEを含む章立てとニュースの順番を保持。章扉の重複追加や削除はしない。
- 図解と比較表はネイティブ図形・テーブルのまま。矢印、単位、数値、比較条件を勝手に変更しない。
- 実資料は必要箇所が見えるようにクロップするが、写真や出典を差し替えない。不良スクショはGeminiへ差し戻す。
- 出典、取得日時、著作者、発表者ノートを維持。未検証はUNVERIFIEDと報告する。
- 編集後の全ページを投影サイズで再確認する。
