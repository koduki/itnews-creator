# PowerPointの視覚修正ルール

**固定テンプレートPPTXが唯一の視覚仕様**。本書では色コード・固定座標・フォントサイズを再定義しません。

- COVER・AGENDA・NEWS_TITLE・NEWS・SOURCE_IMAGE・TECH_DIAGRAM・COMPARE・TWO_SOURCESの役割と、原本の固有スタイルを維持する。特にNEWS以降の本文が青基調であることを守り、旧版の赤系見出しに変更しない。
- 表紙の日付/タイトルが重ならず、章扉の番号と本文のニュース順序が一致することを確認。
- 図解・比較表はネイティブの編集可能な形を維持。矢印方向、条件、単位、数値を変えない。
- スクショ・写真はアスペクト比とニュース証拠としての意味を保つ。Cookie画面やCloudflare画面を隠すだけの対処は不可。Geminiへ再取得を依頼。
- 出典、著作者、取得日、発表者ノートを保持。確認していない項目はUNVERIFIED。
- 実機で全ページの色、画像、文字のはみ出し、可読性を確認してからFINALと報告する。
