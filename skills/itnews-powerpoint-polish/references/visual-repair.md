# ビジュアル修正の原則

- COVERは赤黒の1行タイトル、青い日付枠、元アバターを保持。タイトル・日付の重なりを修正。
- NEWS_TITLEは1ニュースにつき1枚、青いNEWS番号・濃紺見出し・淡青の大番号を残す。
- NEWSなどの本文は赤い見出しと白背景を保ち、汎用の企業向けカードデザインへ変更しない。
- 実画像はアスペクト比とニュースの証拠としての意味を保ち、見せるべき記事の部分を大きくする。不良スクショはGeminiへ再取得依頼。
- 技術図と比較表はネイティブ図形／表のまま。因果、矢印、プロトコル、単位、数値、比較条件を勝手に変更しない。
- 実資料の出典・著作者・取得日時・発表者ノートを維持。確認できない項目はUNVERIFIEDと報告。
- 投影サイズで全ページを再確認し、文字の重なり・はみ出し・図の意味・画像を点検。
