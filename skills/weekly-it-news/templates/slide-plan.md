# Slide storyboard template

Use this internally before calling the host's slide creation tools. Do not render these planning fields as extra slide clutter.

## Deck
- Title:
- Audience and presentation context:
- Deck date / event date:
- Core thesis:
- Main news/technology themes:
- Input source decks or templates:
- Confirmed first-party source list:
- Known unknowns:

## For every slide (repeat)
- **Number / section**:
- **Proposition headline**: (one checkable claim or explicit question)
- **Key takeaway**: (one sentence)
- **Support**: (specific factual claim, number, or an explicit inference)
- **Evidence**: URL, author/publisher, publication date, checked date, evidence strength
- **Visual representation**: editable diagram / native chart / table / real screenshot / photo / text only
- **Why this visual matters**: (what would be lost if removed?)
- **Asset provenance and right to reuse**: (source URL, attribution, permission/restriction status)
- **Editable**: which layers are shapes/text/native chart vs raster
- **Visual-review score**: five dimensions 0–2, reject reasons if any
- **Speaker note**: nuance, forecast label, competing view or methodology

## Example (illustrative, not fact-bearing)
- Proposition: “Three different architectures trade optical openness for compute and weight.”
- Representation: three-column schematic + source-backed table of verified features.
- Reject: photogenic stock photo that gives no architecture information.
- Validation: if any architecture details remain unverified, replace it with a conceptual diagram labeled “模式図” and list the unsupported specifics as unknown.
