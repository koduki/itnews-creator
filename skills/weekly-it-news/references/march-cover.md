# 2026年3月15日版に合わせる表紙（最優先ルール）

**対象は1枚目だけ。** 2枚目以降の目次の現行デザイン・ニュースの構成は変更しない。

## 元スライドからの再現
- ユーザー提供 `20260315.pptx` **1枚目**が元デザイン。白背景、左上に巨大な **赤い `Weekly`** と **黒い `IT` / `News！`**、左側の青いアクセント付き日付枠、右側の赤い「今週のトピック」とその短い予告、右上の正方形アバターが特徴。
- **元の3月版ファイルが同じPowerPointセッションにある場合は、1枚目のネイティブ要素を複製し、日付（年・月・日）と右の予告だけ差し替える。** これが最も忠実。フォントや画像を推測して作り直さない。元の形の重なりが意図しないなら、編集可能性と視認性を損なわない範囲で調整してよいが、大きな構図を変更しない。
- 元ファイルが使えない場合、**スキルに同梱する `assets/cover/weekly-it-news-cover-20260315.pptx`** を使う。必要であれば `templates/march-cover-20260315.json` の座標・色・文字要素を使って**編集可能な図形とテキスト**で再現する。デザインの共通化より、元の表紙の視覚的特徴を優先する。
- 日付は版の日付に更新し、右の予告は今回の主なトピック1件または短い要約に置き換える。ニュース全件の列挙は**2枚目の「今週のトピック」**に任せる。
- 右上のアバターは、元ファイルを複製できる場合は維持。**元の3月版から抽出したアバター `assets/cover/avatar-20260315.jpg` を同梱しているので、追加アップロードは不要。** 別の画像が明示された場合だけ差し替える。出典不明の画像で無断差し替えない。

## 簡易Copilot Chat PPTX生成
- 同梱 `scripts/build_pptx.py` の `layout: "cover"` はこのテンプレートを既定として使う。
- `edition_date` （`YYYY-MM-DD`、無い場合は表紙の `date`）、`cover_teaser` （または `teaser`）、`avatar_image` （任意のローカルPNG/JPG、未指定なら **同梱の原画像**）を使用する。
- 同梱画像が読み込めない場合は、別の架空画像を作って補完せずエラーを明示する。**実画像の埋め込み**を申告するのは実バイトをPPTXへ挿入した場合だけ。
- 2枚目以降の `agenda` レイアウト、ニュース解説レイアウトをこの変更によって改変しない。

## 受け入れ基準
1. 表紙が巨大な赤黒の `Weekly IT News！` と左の日付・右のトピック予告という3月版の構図になっている。
2. 表紙の日付が版の日付と一致する。3月15日など元ファイルの日付を残さない。
3. 元の画像が使えない場合、架空のアバターに置き換えていない。
4. 2ページ目の目次は従来どおり。勝手に3月版の1トピックだけに変更しない。
5. 文字や図形は編集可能。1枚の表紙画像を貼り付けたものは原則不合格。

## 同梱する実リソース
